# Fly Nature Holidays - Premier Travel Studio Website

A premium, responsive, and SEO-optimized website for **Fly Nature Holidays (travel shoppe)**, registered under Kerala Tourism with active branches in Kondotty (Malappuram) and Koduvally (Kozhikode).

Built following modern editorial design principles with a clean White + Brand Orange + Obsidian Black aesthetic, two-column hero composition, 4-column service showcase, 5-step creative process timeline, and interactive pricing estimator.

## 🚀 Key Features

* **Two-Column Hero Section**:
  * Left: Studio label, editorial headline (*"EXPLORE, EXPERIENCE, JOURNEYS & BEYOND"*), supporting narrative, dual CTA buttons, and three trust indicators (*Kerala Tourism Certified, 4.9★ Google Rating, 100% Tailored*).
  * Right: Large layered visual showcase featuring Cappadocia hot air balloons at sunrise, floating departure badge, island permit pass, and traveler rating pill.
* **Docked Quick Search Bar**: Instant package filtering by destination, travel style, and duration.
* **Four-Column Service Cards ("What We Curate")**:
  1. International Holidays & Departures (Turkey, Bali, Thailand, Malaysia, Dubai, Vietnam)
  2. Golden Triangle & Royal Heritage (Delhi, Agra Taj Mahal, Fatehpur Sikri, Jaipur)
  3. Mountain Valleys & Tropical Atolls (Kashmir, Uttarakhand, Lakshadweep Agatti)
  4. Executive Umrah & Pilgrimages (15-day luxury spiritual journeys)
  * Plus 2 secondary highlight categories: Bespoke Honeymoons & Air Ticketing / Visas.
* **Our Travel Planning Process (5-Step Timeline)**:
  * `01 DISCOVER` → `02 STRATEGISE` → `03 SECURE` → `04 REFINE` → `05 EXPERIENCE`
  * Horizontal timeline on desktop, vertical on mobile.
* **Curated Tour Packages (Portfolio)**: Category filter tabs, multi-photo gallery modals, 5-second video reels, and instant WhatsApp booking.
* **Interactive Trip Planner & Estimator**: Real-time package price calculation across 3 comfort tiers (Standard, Deluxe, Luxury).
* **Offices & Instant WhatsApp Enquiry**: Kondotty & Koduvally branch contacts with prefilled WhatsApp forwarding.
* **Admin Dashboard Portal**: Local management of tour packages, categories, and booking inquiries.
* **SEO & Performance**:
  * Schema.org JSON-LD `TravelAgency` structured data.
  * OpenGraph and Twitter card metadata.
  * Static `robots.txt` and `sitemap.xml`.

## 📦 Deployment Instructions

### Deploy to Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` from the root directory.
3. Vercel automatically detects the settings via [`vercel.json`](./vercel.json).

### Deploy to Netlify
1. Install Netlify CLI: `npm i -g netlify-cli`
2. Run `netlify deploy --prod` from the root directory.
3. Netlify automatically reads build instructions and SPA redirects from [`netlify.toml`](./netlify.toml).
